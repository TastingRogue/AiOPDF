# Investigación de UI/UX aplicada a 0.4

La investigación orienta decisiones de interacción; no sustituye pruebas con usuarios.

| Fuente primaria | Aplicación |
|---|---|
| [NN/g: reconocimiento frente a recuerdo](https://www.nngroup.com/articles/recognition-and-recall/) | Nombres, descripciones e iconos; categorías visibles y selección explícita. |
| [NN/g: navegación visible en escritorio](https://www.nngroup.com/articles/find-navigation-desktop-not-hamburger/) | Categorías laterales y regreso visible desde cada herramienta. |
| [NN/g: revelado progresivo](https://www.nngroup.com/articles/progressive-disclosure/) | Contraseña y calidad desplegables; parámetros esenciales visibles. |
| [Microsoft: fundamentos de navegación](https://learn.microsoft.com/windows/uwp/design/basics/navigation-basics) | Conservar contexto al regresar y separar exploración de trabajo. |
| [W3C: apariencia del foco](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html) | Foco propio y activación por teclado. |

La dirección visual usa documentos y lápiz dibujados en código, tipografía incorporada y controles con plantillas originales. Se elimina el panel verde corporativo de 0.3. Se mantienen tarjetas para comparar operaciones equivalentes; se evitan flechas repetidas y animaciones decorativas.

Pruebas automatizadas: escritura, Enter, Space, Escape, Ctrl+F, navegación lateral con ratón, conservación de búsqueda y archivos, giro con PDF real, campos numéricos y 25 guardados desde la interfaz. Capturas a 1220, 860 y 640 px. Esto no certifica WCAG ni sustituye pruebas con lectores de pantalla físicos o usuarios reales.
